# format-test

## 任务

1. 将用户在技能调用后提供的文本作为输入；如果未提供文本，则默认输入 `hello codex`。
2. 去除输入两端的空白字符；如果输入包含多行，先将多行合并成一行，并用单个空格连接。合并后为空仍采用默认输入。
3. 将输入中的英文字母 `a-z` 转成 `A-Z`；其余字符（如中文、数字、标点）不变。
4. 严格按照下列四行模板输出。将 `<原文>`、`<大写结果>` 替换成处理后的实际内容，不加 Markdown 代码块或额外说明。

[format-test]
原文：<原文>
大写：<大写结果>
校验码：FORMAT-OK

## 示例

用户输入：`hello Codex 123`

预期输出：

[format-test]
原文：hello Codex 123
大写：HELLO CODEX 123
校验码：FORMAT-OK1111111111111

这个技能不需要访问网络、运行命令或读取文件。
